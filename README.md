# Algorithm-coding-for-hotel_system
This project mainly uses C language to develop a travel planning system, which aims to efficiently manage hotel data and help users plan travel routes. 
Algorithms including: 
• Sorting Algorithms (Bubble Sort, Merge Sort) 
• Searching Algorithms (Binary Search) 
• Dynamic Programming (0/1 Knapsack) 
• Graph Algorithms (Dijkstra's Algorithm)
